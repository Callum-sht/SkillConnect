## Definition of Done

A task is considered complete when:

* All Acceptance Criteria for the User Story have been met.
* The required functionality has been fully implemented and works as expected.
* User input has been validated where required.
* Relevant tests have been written and passed.
* The feature has been tested by at least one team member.
* The code has been reviewed by another team member.
* No known critical errors remain in the completed feature.
* The code follows the team's agreed coding standards and project structure.
* The completed code has been committed and pushed to the GitHub repository.
* The GitHub Project item has been updated to reflect its current status.
* Relevant project documentation has been updated where required.
